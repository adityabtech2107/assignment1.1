When you type a URL into a client web browser, it initiates a request-response cycle governed by HTTP or its secure counterpart, HTTPS, where the browser sends a request to a remote server asking for the website's files. Depending on whether the site is static—serving fixed, pre-built files directly to the user—or dynamic—where the server processes real-time logic and retrieves information from a database—the server compiles the necessary code (like HTML, CSS, and JavaScript) and sends it back as a response so the browser can finally render and display the complete web page on your screen.

How to get your Network Tab screenshot:
Open Google Chrome and go to any website (e.g., wikipedia.org).

Press F12 (or right-click anywhere on the page and select Inspect).

Click on the Network tab at the top of the DevTools panel.

Refresh the page (F5 or Ctrl+R / Cmd+R) to capture the loading requests.
